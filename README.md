# My Gym

تطبيق آيفون شخصي (React Native + Expo SDK 58 + TypeScript) لحساب السعرات والماكروز، وتسجيل الأكل والتمارين والوزن. كل البيانات محلية في SQLite على جهازك.

## المزايا

- **لوحة اليوم**:
  - حلقة السعرات المتبقية والماكروز.
  - بطاقة **تمرين اليوم** بثلاث حالات: لم يبدأ، قيد التنفيذ، **مكتمل ✓**.
  - شريط أيام الأسبوع لمتابعة التزامك.
- **التغذية (أسلوب MyFitnessPal)**:
  - كل طعام محفوظ بقيمه لكل 100 غ أو 100 مل، وتسجّله بالغرام أو المليلتر أو بعدد الحصص.
  - 44 طعامًا شائعًا جاهزًا، وبحث في أطعمتك.
  - مسح الباركود عبر Open Food Facts، وإضافة طعام من الملصق (لكل 100 أو لكل حصة).
  - سعرات سريعة لوجبات المطاعم.
  - تعديل كمية أي عنصر مسجّل بالضغط عليه، ونسخ وجبة من اليوم السابق.
- **التمارين**:
  - جدول أسبوعي، وبرامج جاهزة، ومكتبة 31 تمرينًا بأيقونات أو صورك.
  - هدف الجلسة القادمة (double progression).
  - **مؤقت راحة** يبدأ تلقائيًا بعد كل مجموعة.
  - عدّاد لمدة الجلسة، وملخص عند الإنهاء يشمل الأرقام القياسية الجديدة.
- **التطور**: الوزن ومتوسط 7 أيام مع رسم بياني، والسجل اليومي، والملاحظات.
- **الإعدادات**:
  - الملف الشخصي والهدف (تنشيف، تثبيت، تضخيم).
  - توزيع الماكروز، وسعرات وماكروز يدوية.
  - نسخ احتياطي JSON وCSV وملف .db، واستعادة.

## الحساب

- **احتياج الثبات** = معادلة Mifflin–St Jeor × معامل النشاط. المعامل يشمل التمارين، فلا تُضاف سعرات التمرين مرة ثانية.
- **تعديل الهدف**: التنشيف ‎−20%‎، والتضخيم ‎+10%‎ (قابلان للتعديل). هناك حد أدنى آمن: ‎1500‎ للرجل و‎1200‎ للمرأة.
- **الماكروز**:
  - البروتين: ‎2.2‎ غ/كغ في التنشيف، و‎1.8‎ غ/كغ في التثبيت والتضخيم.
  - الدهون: ‎0.8‎ غ/كغ، وبحد أدنى 20% من السعرات.
  - الكربوهيدرات: الباقي.

## Apple Health

أُزيل الربط مع Apple Health في هذه النسخة. محرك السعرات (`src/services/nutrition/calories.ts`) ما زال يقبل بيانات الصحة (طاقة الراحة، والطاقة النشطة، وتقدير نهاية اليوم، ومنع الاحتساب المزدوج)، وأنواعها في `src/services/health/types.ts`.

لإعادته لاحقًا:
1. أضف مكتبة HealthKit، مثل `@kingstinct/react-native-healthkit`، مع الـ config plugin الخاص بها.
2. اكتب خدمة تملأ `HealthDay` و`HealthBaseline`.
3. مرّر هذه البيانات إلى `estimateEnergy` في `src/hooks/AppData.tsx`.

## الخصوصية

- لا يوجد أي خادم.
- يُرسل **رقم الباركود فقط** إلى Open Food Facts عند المسح.
- صور التمارين وقاعدة البيانات تبقى على جهازك.

## هيكل المشروع

```
src/app/            الشاشات (Expo Router): (tabs)، food/، workout/، exercise/، plan/، scan، library
src/components/     ui (نظام التصميم)، visuals، TodayWorkoutCard، RestTimer، …
src/services/       nutrition (السعرات والماكروز)، food (الأطعمة والباركود)، training (التطور)، backup، photos
src/db/             schema.ts (الترحيلات v1→v4)، repo.ts (الاستعلامات)
src/__tests__/      43 اختبارًا، منها ترحيل قاعدة البيانات على SQLite حقيقي
```

## التشغيل

إذا كان PowerShell يمنع السكربتات، استخدم `npm.cmd` و`npx.cmd`.

اختبارات الحسابات وقاعدة البيانات:

```bash
npm.cmd test
```

```bash
npx.cmd tsc --noEmit
```

```bash
npx.cmd expo lint
```

التشغيل على الآيفون عبر Expo Go، مع نفس شبكة الواي فاي:

```bash
npx.cmd expo start --go -c
```

نسخة مستقلة مثبتة على الآيفون عبر EAS (تحتاج حساب Apple Developer):

```bash
npx.cmd eas-cli@latest build --profile development --platform ios
```
